## 导入平台

1. 在平台新建“图书馆与知识服务”普通文档知识库，上传六份 Markdown 并执行解析；也可以按上述主题分别建立知识库。
2. 需要精确问答时，新建对应的问答库，使用各主题 CSV 或合并 CSV 导入。CSV 为 UTF-8，表头与平台模板一致：`question,answer`。CSV 应使用问答库导入入口。
3. 文档解析成功、问答导入完成后，在知识问答应用中绑定对应普通知识库和问答库，检查配置并发布。

## 验收问题

可以依次提问：“图书馆几点关门？”、“晚上六点还能借书吗？”、“本科生能借几本书？”、“借出的书可以续借吗？”、“在家怎么访问数据库？”、“我借的书什么时候到期？”。

前五项应返回对应的规则或通用流程，并保留演示资料的适用范围。最后一项应说明需要查询本人读者系统，不能编造个人借阅记录。询问节假日、实时余位、真实奖助政策时，资料不足应明确说明，不应套用普通教学周或演示数字。

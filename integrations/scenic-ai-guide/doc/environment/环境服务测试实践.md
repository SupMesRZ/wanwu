# 环境服务测试实践

记录项目接入阿里云智能语音交互（NLS）、百炼 Embedding、Qdrant 向量库过程中踩过的坑和验证通过的写法。

---

## 一、NLS 语音服务

### 1.1 环境准备

**环境变量**

```powershell
$env:ALIYUN_ACCESS_KEY_ID = "你的AccessKey ID"
$env:ALIYUN_ACCESS_KEY_SECRET = "你的AccessKey Secret"
$env:NLS_APP_KEY = "你的NLS AppKey"
```

AK/SK 需要 RAM 授权 NLS 调用权限，否则 `AccessToken.apply()` 会静默失败（返回 null token）。仅 OSS 权限不够。

**Maven 依赖**

NLS SDK 不在 Maven Central，需添加阿里云仓库：

```xml
<repositories>
    <repository>
        <id>aliyun</id>
        <name>阿里云公共仓库</name>
        <url>https://maven.aliyun.com/repository/public</url>
    </repository>
</repositories>
```

依赖坐标（按功能拆分）：

```xml
<!-- 语音合成 TTS -->
<dependency>
    <groupId>com.alibaba.nls</groupId>
    <artifactId>nls-sdk-tts</artifactId>
    <version>2.2.19</version>
</dependency>

<!-- 实时语音识别 ASR -->
<dependency>
    <groupId>com.alibaba.nls</groupId>
    <artifactId>nls-sdk-transcriber</artifactId>
    <version>2.2.19</version>
</dependency>
```

### 1.2 配置类设计

全局复用 `NlsClient`：

```java
@Bean
public AccessToken accessToken() throws Exception {
    AccessToken token = new AccessToken(accessKeyId, accessKeySecret);
    token.apply();
    // AccessToken.apply() 内部出错时只打印日志不抛异常，此处兜底检查
    if (token.getToken() == null || token.getToken().isBlank()) {
        throw new IllegalStateException("NLS Token 获取失败，请检查 AK/SK 和 RAM 权限");
    }
    return token;
}

@Bean
public NlsClient nlsClient(AccessToken accessToken) {
    return new NlsClient("wss://nls-gateway.cn-shanghai.aliyuncs.com/ws/v1", accessToken.getToken());
}
```

### 1.3 踩坑记录

**坑 1：SpeechSynthesizer 构造函数参数陷阱**

```java
// 构造函数 1：不传 token，使用 NlsClient 自带的 token
public SpeechSynthesizer(NlsClient client, SpeechSynthesizerListener listener)

// 构造函数 2：第二个参数是 token！不是 appKey！
public SpeechSynthesizer(NlsClient client, String token, SpeechSynthesizerListener listener)
```

错误写法：`new SpeechSynthesizer(nlsClient, appKey, listener);` // appKey 被当成了 token，导致 403

正确写法：
```java
SpeechSynthesizer synthesizer = new SpeechSynthesizer(nlsClient, listener);
synthesizer.setAppKey(appKey);
```

**坑 2：RAM 权限不足**

`AccessToken.apply()` 内部发起 HTTP 请求获取 token。如果 AK/SK 没有 NLS 服务权限，`apply()` 会静默失败（异常被 catch 后只打印 `e.printStackTrace()`），`getToken()` 返回 null。

症状：`NlsClient` 连接时返回 `403 Forbidden: token 'xxx' is invalid`

解决：RAM 控制台添加 `AliyunNLSFullAccess`

**坑 3：AccessToken.apply() 静默失败**

`apply()` 内部所有异常都被捕获且不抛出。解决：配置类中 `apply()` 后手动检查 token 是否为空。

### 1.4 对象生命周期

| 对象 | 复用策略 | 原因 |
|------|---------|------|
| `NlsClient` | **全局单例** | 线程安全，创建开销大 |
| `AccessToken` | **全局单例** | 有有效期，过期前复用 |
| `SpeechSynthesizer` | **每次新建** | 非线程安全 |
| `SpeechTranscriber` | **每次新建** | 非线程安全 |
| `FlowingSpeechSynthesizer` | **每次新建** | 非线程安全 |
| Listener | **一一对应** | 不能多个任务共用 |

## 二、Embedding + Qdrant 向量检索

### 2.1 配置

**application.yaml**

```yaml
spring:
  ai:
    model:
      embedding: openai
    openai:
      embedding:
        # 注意：base-url 不带 /v1，Spring AI 自动追加 /v1/embeddings
        base-url: https://dashscope.aliyuncs.com/compatible-mode
        api-key: ${API_KEY_EMBEDDING}
        options:
          # 百炼 OpenAI 兼容接口支持的文本向量模型
          model: text-embedding-v4

qdrant:
  host: ${QDRANT_HOST:localhost}
  port: ${QDRANT_GRPC_PORT:6334}
  collection-name: ${QDRANT_COLLECTION:scenic_knowledge}
```

**踩坑：模型名称**

`qwen3-vl-embedding` 是多模态向量模型，OpenAI 兼容接口不支持，调用会返回：
```json
{"error":{"message":"Unsupported model `qwen3-vl-embedding` for OpenAI compatibility mode."}}
```

应使用 `text-embedding-v4`（Qwen3-Embedding 系列，默认 1024 维，支持 100+ 语种）

### 2.2 切片策略

测试采用简单策略，按 Markdown `###` 标题切分：

- 每个 chunk = 标题 + 正文
- 正文超过 800 字时，按句号二次切分（保持语义完整）
- 过滤少于 30 字的碎片
- Payload 存储来源文件名、章节标题、chunk 索引、原始文本

2 个讲解词文件共生成 12 个切片，平均每个切片约 300-500 字。

### 2.3 Qdrant Java Client API（1.18.1）

```java
// 创建 collection
Collections.VectorParams params = Collections.VectorParams.newBuilder()
    .setSize(dimension)
    .setDistance(Collections.Distance.Cosine)
    .build();
qdrantClient.createCollectionAsync(collectionName, params).get();

// 写入 points（带 payload）
Points.PointStruct point = Points.PointStruct.newBuilder()
    .setId(Common.PointId.newBuilder().setNum(id))
    .setVectors(Points.Vectors.newBuilder()
        .setVector(Points.Vector.newBuilder().addAllData(vectorList).build())
        .build())
    .putPayload("text", JsonWithInt.Value.newBuilder().setStringValue(text).build())
    .build();
qdrantClient.upsertAsync(collectionName, List.of(point)).get();

// 搜索（必须使用 SearchPoints builder）
Points.SearchPoints search = Points.SearchPoints.newBuilder()
    .setCollectionName(collectionName)
    .addAllVector(queryVector)
    .setLimit(3)
    .setWithPayload(Points.WithPayloadSelector.newBuilder().setEnable(true).build())
    .build();
List<Points.ScoredPoint> results = qdrantClient.searchAsync(search).get();
```

**注意**：
- `PointId` 在 `io.qdrant.client.grpc.Common` 包下，不在 `Points` 下
- `searchAsync` 只接受 `SearchPoints` 参数，不接受分开的 `(collection, vector, limit)`
- `countAsync(String)` 返回 `Long`，不是 `CountResult`
- `Embedding.getOutput()` 返回 `float[]`，不是 `List<Double>`

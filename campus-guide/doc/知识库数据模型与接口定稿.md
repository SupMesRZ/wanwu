# 知识库数据模型与接口定稿

> 本文记录知识库第一阶段数据模型和接口契约。知识库负责 AI 内容维护，不维护地图空间数据。

## 1. 页面范围

第一阶段实现：

- 知识文档
- 文档切片
- FAQ
- 讲解词

## 2. 归属范围

知识库内容只归属于景区：

```text
scenic_area_id = 景区 ID
```

知识库不绑定景点、服务点、路线或地图草稿。AI 问答通过景区级知识库、当前位置上下文和景点名称上下文提高召回准确性。

## 3. 数据表

### qa_knowledge_doc

知识文档元数据。

```text
id
scenic_area_id
title
file_name
file_url
doc_type
summary
parse_status
vector_status
chunk_count
status
created_at
updated_at
deleted
```

### qa_knowledge_chunk

文档切片。

```text
id
doc_id
scenic_area_id
chunk_index
content
vector_id
token_count
hit_count
vector_status
status
created_at
updated_at
deleted
```

### qa_faq

高频问答。

```text
id
scenic_area_id
question
answer
category
tags
hit_count
status
created_at
updated_at
deleted
```

### qa_guide_script

景区级预置讲解词。

```text
id
scenic_area_id
title
content
language
priority
audio_asset_id
video_asset_id
status
created_at
updated_at
deleted
```

## 4. 接口

### 知识文档

```text
GET    /api/v1/admin/qa/knowledge-docs
POST   /api/v1/admin/qa/knowledge-docs
PUT    /api/v1/admin/qa/knowledge-docs/{id}
DELETE /api/v1/admin/qa/knowledge-docs/{id}
POST   /api/v1/admin/qa/knowledge-docs/{id}/reindex
GET    /api/v1/admin/qa/knowledge-docs/{id}/chunks
```

### 文档切片

```text
GET /api/v1/admin/qa/knowledge-chunks
```

### FAQ

```text
GET    /api/v1/admin/qa/faqs
POST   /api/v1/admin/qa/faqs
PUT    /api/v1/admin/qa/faqs/{id}
DELETE /api/v1/admin/qa/faqs/{id}
```

### 讲解词

```text
GET    /api/v1/admin/qa/guide-scripts
POST   /api/v1/admin/qa/guide-scripts
PUT    /api/v1/admin/qa/guide-scripts/{id}
DELETE /api/v1/admin/qa/guide-scripts/{id}
```

## 5. 第一阶段非目标

- 不接真实文件上传
- 不接真实 Qdrant 写入
- 不做完整 RAG 问答链路
- 不把知识库内容写回景区、景点、服务点、路线或地图草稿表
- 不维护资料和地图对象的绑定关系

## 6. 第一阶段验收

- 知识文档可增删改查
- 文档按景区维护
- 文档重建索引会生成模拟切片
- 文档切片可查询
- FAQ 可增删改查
- 讲解词可增删改查
- 后端接口统一返回 `ApiResponse`
- 前端知识库页面可关闭 mock 走真实接口
